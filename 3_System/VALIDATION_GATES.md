# VALIDATION GATES — Fixed Validation Rules

**Read BEFORE any important decision.**

Any idea or project that doesn't pass the relevant gates does NOT go into execution, no matter how promising it seems.

---

## Gate 1: Skeptic Check

**Rule:** Before any high-stakes decision, run a Skeptic check — ask the Skeptic agent to attack the idea from 3 angles. If it survives, you can continue.

---

## Gate 2: Real Data, Not Impressions

**Rule:** Any decision is based on measurable data, not "it feels right". If you don't have data, collect it first.

---

## Gate 3: Minimum Viable — Not Perfection

**Rule:** The first version must be functional, not perfect. Launch, then iterate. If you wait for perfection, you never launch.

---

## Gate 4: One Thing at a Time

**Rule:** Max 1 major project in execution. Before starting something new, finish or pause what's in progress.

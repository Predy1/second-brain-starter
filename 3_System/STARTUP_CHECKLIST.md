# Session Startup Checklist

At the start of every session, AFTER reading HOTCACHE.md and SESSION.md, ask the user:

---

## 1. PLAN
"Do we have a plan for this session? Let's write the steps in SESSION.md before we start."
- If SESSION.md already has a plan: "That's the plan from last session. Do we continue or adjust?"
- If there isn't one: 3-7 steps, written before the first task.

## 2. DO NOT
"For the current task: what don't you want touched? Which files stay intact? Which directions do we ignore?"

## 3. VERIFICATION
After each AI answer: "Is the direction OK? Confirm before I continue?"
- Don't proceed without confirmation when the task is complex.
- For simple tasks (read-only, searches), it's not necessary.

## 4. ONE OUTCOME
If the user starts a new direction halfway: "That's a new direction. Do we save it for the next session or abandon the current task?"
- Max 1 major topic per session.
- If new ideas appear → note them in SESSION.md under "🔜 Next", don't execute now.

## 5. FINAL DEBRIEF
At the end of the session, ask for 3 lines and write them in SESSION.md:
```
✅ What went well:
❌ What didn't:
🔜 Next:
```

---

**Note:** These are guidelines, not chains. If the user says "skip, I know what I'm doing", respect that — but you asked.
